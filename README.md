# ZAFRIK MOCKUP TAZAS PRO

Aplicación React + Vite preparada para publicar como Static Site en Render.

## Ejecutar localmente
1. Instalar Node.js LTS.
2. Abrir una terminal en esta carpeta.
3. Ejecutar `npm install`.
4. Ejecutar `npm run dev`.

## Publicar en Render
1. Subir este proyecto a un repositorio GitHub.
2. En Render, crear un servicio **Static Site** y conectar el repositorio.
3. Build Command: `npm install && npm run build`
4. Publish Directory: `dist`
5. Deploy.

## Estado de esta primera versión
Incluye interfaz inicial, agregar/quitar tazas, selección individual, carga de diseño y fondo, controles básicos y exportación PNG local.
La división panorámica real entre tazas y la deformación cilíndrica avanzada quedan identificadas como siguientes módulos de desarrollo. La vista actual es una maqueta funcional inicial, no una simulación física final de impresión.
